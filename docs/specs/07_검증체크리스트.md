# 검증 체크리스트

**심사 직전 30분에 이 문서만 돌려라.** 아래는 전부 "실제로 한 번은 틀렸던" 항목이다.

---

## A. 숫자 — 5분

[계산명세 §10 검산표](02_계산명세.md)와 화면을 대조한다.

- [ ] A 싱가포르 **$2,916** (운임 2,840 · 탄소 67 · 보험 9)
- [ ] D 콜롬보 **$3,021** (운임 2,900 · 탄소 67 · 보험 54)
- [ ] C 희망봉 **$3,286** (운임 3,200 · 탄소 86 · 보험 **0**)
- [ ] B 홍해 **산출 안 함**
- [ ] 안전 확보 추가비용 **+$370 (12.7%)**
- [ ] 적용거리 A/B **11,259** · D **11,317** · C **14,549** nm
- [ ] 최대 선적 가능일 **2026-08-10** · 문전-문전 **65일**
- [ ] 탄소비용이 2배로 나오지 않는다 → **적용범위 0.5** 확인

## B. 제품이 자기 말을 뒤집지 않는가 — 5분

- [ ] **B 행을 펼쳐서** 금액이 없는지 확인 (접힘만 보지 말 것)
- [ ] 펼침에 **최대 선적일도 없는지** 확인
- [ ] 추천이 최저가가 아니라 **`best` 상태 중 최저가**인지 (싱가포르가 추천되면 틀렸다)
- [ ] 화면 어디에도 **"최적 선적일을 권고"** 류 문구가 없는지
- [ ] 중앙선을 **"예측"이 아니라 "기준선"** 이라 부르는지
- [ ] 인코텀즈 설명에 **"화주"** 가 없는지 (매도인/매수인이어야 한다)
- [ ] 소개 화면과 앱 화면이 **같은 금액·같은 추천 항로**를 말하는지

## C. 인코텀즈 — 3분

- [ ] FOB → 매수인 **$3,286** / 매도인 **$0**
- [ ] CIF → 매수인 **$0** / 매도인 전액
- [ ] CIF 로 바꿀 때 **화물가액 칸이 열리고** 조건 바가 안 깨지는지
- [ ] 가액 없이 CIF → 보험료가 **"입력 필요"** 로 뜨는지 (임의 값 금지)

## D. 지도 — 2분

- [ ] 희망봉 경로가 **실제로 아프리카 남단**을 돈다 (파나마/태평양으로 안 간다)
- [ ] 선이 지도를 **가로지르지 않는다** (경도 unwrap)
- [ ] 표의 적용거리와 지도의 선이 **같은 계산**에서 나왔다

## E. 실시간 연동 — 3분

- [ ] EUA 시세가 살아 있고 **헤더 등락률이 같은 응답의 값**과 일치
- [ ] 환율 각주가 **"실시간"** 으로 뜬다 (폴백이면 그렇게 표기)
- [ ] 환율 출처 표기가 화면에 있다
- [ ] API 를 꺼도 **화면이 안 죽고** 폴백으로 뜬다

## F. 각주 — 3분

[화면명세 §8](04_화면명세.md) 표를 그대로 훑는다.

- [ ] 가정값에 **"가정값"** 이라고 쓰여 있다 (정시운항율 · 리드타임 · 보험 요율)
- [ ] 콜롬보 0.6% 가 **자체 추정**이라고 밝혀져 있다
- [ ] EUA 가 **프록시**라고 밝혀져 있다
- [ ] 추정 창(260거래일)과 검증 표본(1,728일)이 **구분**돼 있다
- [ ] 북극항로를 **범위에서 제외**한 사유가 적혀 있다

## G. AI — 5분 (붙였다면)

- [ ] 같은 규정 질문 **3회**에 같은 조문을 인용하는지
- [ ] 근거에 없는 걸 물으면 **"확인되지 않습니다"** 라고 하는지
- [ ] AI 답변의 금액이 **화면 금액과 일치**하는지 (다시 계산하면 안 된다)
- [ ] 없는 항만을 말하면 **`unsupported`** 로 처리되는지
- [ ] 항로 비교 리포트가 **상태 사유를 근거로** 언급하는지
- [ ] API 키가 죽어도 **계산 기능은 멀쩡**한지

## H. 안 깨지는가 — 4분

- [ ] 탭 5개를 **빠르게 연속 클릭**해도 안 터진다 (지도 초기화 경합)
- [ ] 콘솔 에러 **0**, 실패 요청 **0**
- [ ] 조건을 여러 번 바꿔도 값이 따라온다
- [ ] 인코텀즈를 **왔다갔다** 해도 레이아웃이 안 깨진다
- [ ] 좁은 화면에서 **가로 스크롤이 안 생긴다**

## 시연 대본 — 90초

이 순서면 명제가 순서대로 드러난다.

| 초 | 무엇 | 말할 것 |
|---|---|---|
| 0-15 | 조건 입력 → 검색 | "부산에서 함부르크, 20피트, 납기 10월 5일" |
| 15-35 | 표 | "운임 최저는 싱가포르 $2,840. **그런데 추천은 희망봉입니다**" |
| 35-50 | **B 행 펼침** | "홍해는 봉쇄라 **총비용을 아예 만들지 않습니다**" |
| 50-65 | C 행 펼침 | "희망봉은 운임이 비싼데 **보험료가 0**입니다. +$370로 안전을 삽니다" |
| 65-80 | **인코텀즈 CIF 전환** | "같은 총비용도 누가 내느냐가 갈립니다. 매수인 직접 지출은 0 — **사라진 게 아니라 상품가로 옮겨간 겁니다**" |
| 80-90 | 납기 역산 | "8월 10일까지는 실어야 납기를 맞춥니다" |

**35-50초와 65-80초가 이 데모의 두 절정이다.** 다른 걸 못 보여줘도 이 둘은 보여줘라.

## 질문이 나오면 — 미리 답을 정해둘 것

| 질문 | 답 |
|---|---|
| "왜 4개 항로뿐인가?" | 상용 정기선 기준. 북극항로는 계절 제약(연 4~8개월)과 쇄빙선급 요건으로 범위 제외 — 화면 각주에 있다 |
| "가격 예측은 안 하나?" | **못 한다.** 1,728일 워크포워드에서 AIC 24회 전부 랜덤워크를 골랐다. 그래서 구간과 확률만 주장한다 |
| "확률은 얼마나 믿을 만한가?" | 80% 구간 포함률 82.3%로 잘 맞는다. **다만 보정오차 ECE 0.0392로 기후값 기준선(0.0294)보다 나쁘다** — 그래서 확률은 보조 지표로만 쓴다 |
| "숫자를 AI가 만든 건가?" | 아니다. 금액·확률은 엔진 계산값이고 LLM 은 파라미터 추출과 서술만 한다 |
| "0.6% 요율 근거는?" | A(0.1%)와 B(0.75%) 사이 **자체 보간 추정치**다. 특정 기사 인용이 아니라고 화면에 밝혔다 |
| "정시운항율 출처는?" | **가정값**이다. 실서비스는 업계 공표 자료를 연동해야 한다 — 화면에 그렇게 표기했다 |
| "EUA 데이터는 거래소 직접인가?" | 아니다. **프록시**(EUA 실물 1:1 보유 ETC + 스플라이싱)다. 각주에 밝혔다 |

> **모르는 걸 아는 척하지 마라.** 이 제품의 강점은 "못 하는 걸 못 한다고 말하는 것"이고,
> 심사위원은 그걸 본다.
