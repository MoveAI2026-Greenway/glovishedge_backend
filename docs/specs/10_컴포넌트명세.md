# 컴포넌트 명세 — 무엇을 몇 개 만들고, 무엇을 주고받나

[화면명세](04_화면명세.md)가 **생김새**라면 이 문서는 **구조와 동작**이다.
개발 지시를 이 문서 단위로 쪼개 나눠 주면 된다.

---

## 1. 모듈 경계 — 이 경계만 지키면 안이 어떻게 생겼든 상관없다

```
데이터 (순수 상수·시드)
   └─ 항구 · 항로 · 화물단위 · 인코텀즈 · 위험구역 · 시계열 시드

계산 (순수 함수 — 화면을 모른다)
   ├─ 배출량/탄소비용        거리 → tCO2 → EUR → USD
   ├─ 전쟁위험보험료          선체가치 × 단위 × 요율
   ├─ 인코텀즈 귀속           금액 3종 → 매수인/매도인/보험
   ├─ 납기 역산               항로+납기 → 최대선적일·충족여부
   ├─ 항로 평가(오케스트레이터) 위 넷을 합쳐 표 한 줄을 만든다
   └─ 리스크 엔진             EWMA · 구간 · 도달확률 · 예산리스크

서버 (외부와 붙는 곳)
   ├─ 시세/환율 프록시 (캐시+폴백)
   ├─ 항로거리 계산 (오프라인)
   ├─ 규정 색인 검색
   └─ LLM 게이트 (키는 여기서만)

화면 (계산을 하지 않는다 — 받은 값을 그린다)
```

**규칙 하나**: 화면에서 상수를 다시 import 해 계산하지 마라. 요율·적용범위·거리는
**계산 결과에 실어 내려보낸다.** 안 그러면 계산과 표기가 갈라진다.

## 2. 계산 결과 객체 — 표 한 줄이 받는 것

항로 평가가 **항로 1개당** 아래를 돌려준다. 화면은 이것만 보고 그린다.

```jsonc
{
  // 식별·표시
  "key": "C", "id": "cape_bypass", "name": "희망봉 우회",
  "status": "best",                  // best | limited | blocked
  "statusReason": "위험구역을 전혀 지나지 않아…",   // 배지 툴팁 + AI 가 같은 문장을 쓴다
  "laneNote": "인도양 → 희망봉 · 보험료 없음",
  "riskLevel": "안전", "riskScore": 0,

  // 거리
  "distanceNm": 14549,               // 실제 적용된 거리(반올림)
  "refDistanceNm": 14500,            // 데이터에 적힌 참고값
  "distanceSource": "searoute",      // searoute | scaled  ← 폴백 여부를 화면이 알 수 있다
  "path": [[lat, lng], …],           // 지도가 그대로 그린다. 없으면 null

  // 비용
  "co2PerUnitTon": 1.8877,           // 물리 배출량(과금 대상 아님)
  "carbonCostEur": 74.58,
  "carbonCostUsd": 86.13,            // ⚠ 반올림하지 않는다
  "baseFreightUsd": 3200,
  "warRiskUsd": 0,
  "warRiskRatePct": 0,               // 화면이 "요율 0.75%"를 쓸 수 있게 함께 내려보낸다
  "totalUsd": 3286,                  // blocked 이면 null

  // 인코텀즈 귀속
  "buyerUsd": 3286, "sellerUsd": 0,
  "insuranceUsd": 0, "insurable": false,

  // 납기
  "leadTimeDays": 52, "transitDays": 56,
  "maxShipDate": "2026-08-10", "daysUntilMaxShip": 17,
  "meetsDeadline": true, "overageDays": 0
}
```

**전체 결과**는 `{ evaluated, feasible, recommended }` 세 벌이다.
`evaluated` 는 전부, `feasible` 은 납기 충족, `recommended` 는 한 개.

## 4. 상호작용 규칙 (여기가 자주 어긋난다)

| 상황 | 기대 동작 |
|---|---|
| 조건 값 변경 | 버튼 없이 **즉시** 재계산 |
| `검색` 클릭 | 결과(KPI)로 스크롤. 재계산은 이미 끝나 있다 |
| 로고 클릭 | 소개 화면으로. **조회 조건은 유지** |
| 인코텀즈 CIF 선택 | **화물가액 칸이 추가로 열린다.** 바 레이아웃이 깨지면 안 된다 |
| 행 펼치기 | 한 번에 **하나만** 열린다 |
| 운항 불가 행 | 비교 체크박스 **비활성** + 펼침에 금액 없음 |
| 비교 2개 초과 | 3번째 체크박스 **비활성** |
| 배지 hover | `statusReason` 툴팁 |
| 지도 선 hover | 상태와 근거 표시 |
| 탭 전환 | 지도 초기화와 경합하지 않게 ([함정 10](06_함정목록.md)) |
| 파일 첨부 | 바로 판정하지 말고 **입력창에 텍스트를 채운다** |
| 목표가 알림 켜기 | **즉시 한 번 판정** — 이미 도달했으면 그렇게 답한다 |

## 5. 차트 사양

### 팬차트 (선적 시점 분석)

- x축: 영업일. **오늘 기준선**을 세로로 긋는다
- 실적 선 + 중앙선(드리프트 0) + 80% 밴드 + 95% 밴드(더 옅게)
- 중앙선을 "예측"이라 부르지 않는다 → **"중앙(수평)"**
- 우측에 오늘 탄소비용 / 14영업일 80% 범위 / 변동성 국면 카드

### 10칸 와플 (비용 구성)

- 가장 비싼 항로 대비 비율을 **10칸**으로 표시(적을수록 싸다)
- 칸 안의 색이 구성 — 운임(네이비) · 탄소(블루) · 전쟁위험(앰버)
- **알려진 한계**: 해상도가 10%라 12% 차이를 9칸 vs 10칸으로밖에 못 가른다.
  운임이 97%라 탄소·보험 색도 거의 안 보인다. 시안 목업의 6+3+1 은 **실제 데이터로는
  나올 수 없는 그림**이다. 시안을 따르되 이 사실을 알고 있어라

### 리드타임 막대 (공급망)

- 6구간 가로 스택. 해상 구간만 항로별로 바뀐다
- 구간별 색은 회색 계열 농도로 구분(출발측 밝게 → 도착측 어둡게)

## 6. 서버 라우트 구성

```
/api/eua              시세 (30분 캐시 · 스냅샷 폴백)
/api/fx               환율 (24시간 캐시 · 상수 폴백)
/api/sea-distance     거리+경로 (오프라인)
/api/compare-routes   항로 비교 리포트 (LLM)
/api/chat             어시스턴트 단일 진입점 (봇 7종)
/api/rag/ask          규정 검색 (색인 + LLM)
/api/extract-text     계약서 → 텍스트
/api/auth/*           회원가입·로그인·세션
/api/alerts           목표가 알림
```

- 정적 파일 서빙 + SPA 폴백을 같은 서버가 한다
- ⚠ SPA 폴백은 **없는 경로에도 200 + index.html** 을 돌려준다.
  자산 존재 확인을 `200` 으로 판단하면 오진한다 — **content-type 을 봐라**
- 게이트웨이가 서브경로(`/<slug>/`)로 프록시하므로 **자산은 상대 경로**를 쓰거나
  base path 를 설정해야 한다

## 7. 인증·알림 (T3 이하 — 시간 남을 때)

- 비밀번호는 **scrypt 해시**로만 저장. 비교는 타이밍 안전 비교
- 세션은 httpOnly 쿠키(SameSite=Lax)
- 알림 등록 시 **즉시 도달 판정**하고 상태를 `sent` / `pending` 으로 구분해 돌려준다
- 데모 계정은 재배포 시 초기화된다고 화면에 밝힌다
