## 2. 배포 — 접속 주소를 하나로 고정하라

### 왜 호스팅 URL 을 그대로 쓰면 안 되나

- 재배포하면 **주소가 바뀔 수 있다**. QR·문서에 박아둔 링크가 죽는다
- 유휴 절전을 쓰면 **잠든 사이 404** 가 뜬다. 심사위원이 "사이트가 죽었다"고 판단한다

### 그래서

**앞단에 고정 주소(게이트웨이)를 두고 제출물에는 그 주소만 쓴다.**

```
제출물(QR·링크·영상 엔드카드) → 고정 주소 → (프록시) → 실제 호스팅
```

- 서버가 잠들어 있으면 게이트웨이가 **로딩 페이지를 띄우고 깨운다**(20~40초)
- 심사위원이 첫 접속에 로딩을 보는 건 **정상 동작**이다. 안내 문구를 띄워라
- **헬스체크는 반드시 고정 주소로** 한다. 호스팅 주소가 404 라고 장애로 오진하지 마라

### 서브경로 함정

게이트웨이가 `/<slug>/` 아래로 프록시하면 **절대 경로 자산이 전부 깨진다.**

- 자산은 **상대 경로**를 쓰거나 base path 를 설정한다
- 라우터도 같은 base 를 알아야 한다
- ⚠ **HTML 이 200 이라고 정상이 아니다.** SPA 폴백은 없는 경로에도 200 + index.html 을
  돌려준다. 실제로 렌더되는지, 실패 요청이 없는지 **브라우저로 확인**하라

## 3. 배포 전 점검

- [ ] **빌드본**을 서빙한다(개발 서버 아님)
- [ ] 환경변수(키)가 서버에만 있고 **번들에 안 들어갔다**
- [ ] 외부 API 를 전부 막아도 **화면이 뜨고 계산이 된다**
- [ ] 게이트웨이 주소로 접속 → 전 탭 순회 → **콘솔 에러 0 · 실패 요청 0**
- [ ] 영상 파일이 서빙되고 **재생**된다(206 Partial Content 로 스트리밍되는지)
- [ ] 모바일 폭에서 가로 스크롤이 없다

> **번들 해시로 배포를 확인하지 마라.** 빌드가 비결정적이면 같은 소스에서도 해시가 다르다.
> **새로 넣은 문구를 배포본에서 grep** 하거나 **실제로 열어서** 확인하라.

## 4. 제출 직전 30분

[검증 체크리스트](07_검증체크리스트.md)를 돌린 뒤 아래를 확인한다.

- [ ] 세 산출물의 **수치가 전부 같다**(덱 ↔ 영상 ↔ 화면)
- [ ] 셋 다 **같은 주장**을 한다 — 방향 예측 안 함 / 운항 불가는 총비용 없음 / 숫자는 엔진
- [ ] 덱 표지에 **팀원 실명**
- [ ] 영상 엔드카드 URL = 제출 링크 = 덱의 데모 링크 (**셋이 같은 주소**)
- [ ] `TBD`·`추후 작성` 이 어디에도 없다(발표자 노트 포함)
- [ ] 파일명 날짜와 표지 제출일이 같다

## 5. 시연 중 사고 대비

| 사고 | 대비 |
|---|---|
| 현장 인터넷이 끊긴다 | **로컬에서도 돌아가게** 해두고, 노트북에 띄워둔 화면을 그대로 쓴다 |
| 외부 API 가 죽는다 | 폴백이 동작하는지 미리 확인. 각주가 "폴백"으로 바뀌는 것도 정상 동작이다 |
| 서버가 잠들어 있다 | 발표 **5분 전에 한 번 열어** 깨워둔다 |
| LLM 키가 막힌다 | AI 기능만 접고 계산 기능으로 시연한다. **T1 은 LLM 없이 완결된다** |
| 영상이 안 열린다 | 로컬 파일을 따로 준비한다 |

**발표 5분 전 루틴**: 게이트웨이 주소 열기 → 조건 넣고 검색 → 표가 뜨는지 →
B 행 펼쳐서 금액 없는지 → 영상 재생 확인.
