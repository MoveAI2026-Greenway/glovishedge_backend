# 화면 명세

Figma 시안은 현장에 **가져간다**. 이 문서는 시안이 말해주지 않는 것 —
**셸 치수 · 색 토큰 · 상태 규칙 · 컴포넌트 목록**을 적은 것이다.

---

## 0. 시안을 볼 때 — 두 가지만 조심

**① 최종 핸드오프 캔버스는 `68:1735` 다.**
같은 파일에 `1:*`(작업) · `91:*` · `99:*`(시안 1차) 세대가 남아 있다. 옛 노드를 보고
"구현이 시안과 다르다"고 오판한 적이 있다. **한 화면 안에 두 세대가 섞이면 안 된다.**

**② 눈으로 보고 옮기지 마라.**
AI 의 design-to-code 충실도는 실측 65~80% 다. 실제로 **콘텐츠 폭 200px 오차**가 앱 전체에
퍼진 뒤에야 발견됐다. 노드에서 좌표·크기·색·타이포를 뽑고 **같은 뷰포트에서 재서** 대조하라.

> Figma API 를 쓴다면 **한 번 받아 로컬에 저장하고 그 캐시로 작업하라.**
> 무거운 조회를 연달아 날리면 429 가 나고, 무료 플랜은 `Retry-After` 가 **40시간** 넘게 잡힌다.

> 헤더만 옛 시안을 따르면 **한 화면 안에 두 세대가 섞인다.** 실제로 그 상태였다.

**시안을 따르지 않는 곳이 딱 하나 있다** — 소개 화면 Feature2 카피.

실측 검증에서 방향 예측이 불가능하다고 결론 났다. **레이아웃·크기·색은 시안 그대로 두고
주장만 구간 중심으로 바꾼다.** 이건 실수가 아니라 결정이다.

## 3. 드롭다운 — 네이티브 `select` 를 쓰지 마라

네이티브를 열면 **OS 기본 목록**이 뜬다. 시안은 다르다.

| 요소 | 스펙 |
|---|---|
| 패널 | radius **16** · `#FFFFFF` · 옵션 폭 **284** |
| 옵션 | **284 × 73** · radius **10** · padding 14/16 |
| 기본 | 코드 15/600 `#191F28` (자간 0.3) · 설명 14/400 `#8B95A1` (행높이 20.3) |
| **선택** | 배경 `#2563EB` 6% · 코드 `#2563EB` · 우측 ✓ 15/700 `#2563EB` |
| hover | 배경 `#F6F8FB` |
| 검색 행 | 위치핀 26 + 이름 15/700 `#26324B` + 국가 13/500 `#6D7993` |

- **항구 선택은 검색 가능해야 한다.** 목록이 길다. "인천"·"KR" 로 찾아지게 하라
- 패널은 **body 로 포털 렌더 + fixed 위치**로 띄워라. 안 그러면 조건 바가 잘라먹는다
- ⚠ 화면 확대(zoom)를 쓴다면 `html` 이 아니라 **`#root` 에 걸어라.**
  `html` 에 걸면 요소 실측 좌표(시각 좌표)와 fixed 위치(줌 좌표)가 어긋나 패널이 밀린다

## 4. 조건 바 = 입력창 그 자체

**별도 편집 패널을 만들지 마라.** 조건 바를 누르면 그 자리에서 바뀌어야 한다.
(편집 패널을 띄웠다가 "왜 창이 또 뜨냐"고 지적받았다.)

| 필드 | 동작 |
|---|---|
| 출발지 / 도착지 | 검색 가능한 드롭다운 |
| 화물 유형 | 세그먼트 토글 **146 × 38**(안쪽 패딩 3) — 컨테이너 / 완성차 |
| 화물 단위 | 20ft / 40ft / 40ft HC (완성차는 차종 100대) |
| 인코텀즈 | FOB / CIF — **CIF 선택 시 화물가액 칸이 추가로 열린다** |
| 납기일 | 날짜 입력 |
| 검색 버튼 | **90 × 62** · radius 8 · 16/700 |

- 값이 바뀌면 **즉시 재계산**된다(버튼 없이). 검색 버튼은 결과로 스크롤시키는 역할
- ⚠ **인코텀즈를 바꿔도 바 레이아웃이 깨지지 않아야 한다.** CIF 로 바뀌며 칸이 하나
  늘어나기 때문이다 — 실제로 여기서 깨졌다
- 필터 체크박스 3종은 **기본값 전부 꺼짐**. 시안은 "위험구역 회피"가 켜져 있지만
  그러면 **운항 불가인 홍해 직항이 목록에서 사라진다** — "왜 홍해가 없냐"에 답하려고 남긴 행이다

## 5. 항로 비교 표 — 이 화면이 제품이다

**열 구성**: 비교 체크박스 · 순위 · 항로명+상태 · 비용 구성 · 리드타임 · 총비용 · 펼치기

| 요소 | 규칙 |
|---|---|
| 정렬 | 총비용 낮은 순. **운항 불가는 맨 뒤로** |
| 순위 배지 | 24×24 원형 |
| 상태 배지 | 추천 / 제한적 / 운항 불가 — **마우스 올리면 사유(statusReason)가 뜬다** |
| 부제 | 위험·제약 한 줄 (예: "말라카 → 수에즈 · 후티 사정권 밖") |
| 비교 체크박스 | 2개까지. **운항 불가는 선택 불가** |

### 펼침 패널

- 3분해 카드: 기본운임 / 탄소비용(**적용거리 · 적용범위 %** 표기) / 전쟁위험보험료(**요율 %** 표기)
- 인코텀즈 귀속 카드: **매수인(구매자) 부담 / 매도인(판매자) 부담** [+ CIF 면 적하보험료]
- 하단: 최대 선적일 · 최저 총비용 항로 표시

> **요율·거리·적용범위를 화면에 같이 적어라.** "배율 반영"만으로는 검산할 수 없다.
> 이 값들은 **계산 결과에 실어 내려보내라** — 화면에서 상수를 다시 import 하면
> 계산과 표기가 갈라진다.

### 운항 불가 행 — 접힘·펼침 **양쪽** 모두

| | 보여줄 것 | 보여주면 안 되는 것 |
|---|---|---|
| 접힘 | "운항 불가" · "비용을 산출하지 않습니다" · "— 판정 제외" | 3분해 · 총비용 |
| **펼침** | **왜 못 가는지**(봉쇄 사유·요율 급등) · 참고 항로 거리 | **금액 일체 · 최대 선적일** |

거리는 물리적 사실이라 남겨도 된다. **금액은 안 된다.** ([함정 3](06_함정목록.md))

### 범위 각주 — 반드시 남길 것

> 상용 정기선 기준 **4개 항로**를 다룹니다. 북극항로(NSR)는 일부 선사가 시범 운영 중이나
> 계절적 제약(연 4~8개월)과 쇄빙선급 요건으로 상용 서비스에서는 예외적 옵션이라
> 범위에서 제외했습니다.

**빼먹은 게 아니라 범위에서 제외한 것**임을 근거와 함께 남겨라. 안 적으면 심사에서
"왜 뺐냐"가 반드시 나온다.

## 7. AI 어시스턴트 — 접어두지 마라

**우측 상시 패널**(폭 352)이다. 접힌 FAB 버튼이 아니다.

- 액션 카드 4종을 항상 보여준다 — 도달 확률 / 계약 조항 / 규정 / 문서 작성.
  **무엇을 물어볼 수 있는지가 항상 보이는 것**이 요지다
- 어느 경로로 답했는지 **배지로 남긴다**(엔진 / 색인 / 생성)
- 파일 첨부(📎)는 **바로 판정하지 말고 입력창에 텍스트를 채운다** — 무엇이 들어갔는지
  보고 보내라는 뜻이다

## 8. 각주 — 화면이 스스로 한계를 말하게 하라

**이게 이 제품의 성격이고, 구현 비용이 0 이면서 심사에서 가장 강한 부분이다.**

| 자리 | 반드시 적을 것 |
|---|---|
| 총비용 옆 | 인코텀즈와 무관하게 **누가 내든 합계** 기준 |
| 탄소비용 | 적용거리 · **적용범위 50%** |
| 전쟁위험보험료 | 요율 % · 선체가치 기준 · **콜롬보 0.6% 는 자체 추정** |
| 적하보험료 | 요율 0.15% 는 **가정치**(업계 범위 0.05~0.3% 중앙값) |
| 리드타임 | 생산·통관·내륙은 **업계 평균치 기반 가정값** |
| 정시운항율 | **가정값** 칩 |
| 구간 차트 | 중앙선은 **점 예측이 아니라 기준선** |
| EUA 출처 | 거래소 원장이 아닌 **프록시**(CO2.L + GRN 스플라이싱) |
| 환율 | **실시간** / 고정(폴백) 구분 + 출처 표기 |

- 각주 문구는 **함수로 만들어라.** 문자열 상수로 두면 폴백 값이 굳는다 ([함정 6](06_함정목록.md))
- **추정 창(260거래일)과 검증 표본(1,728일)을 뭉뚱그리지 마라** ([함정 16](06_함정목록.md))
