# API 계약 — 현장 최소 구성

전체 명세는 `../API_문서.md`(18개 엔드포인트)에 있다. **이 문서는 현장에서 실제로 만들
최소 집합**과 그 계약만 추린 것이다. 시간이 남으면 원본 명세로 넘어가라.

---

## 0. 구조 원칙 — 이 경계를 지키면 나머지는 자유다

```
브라우저 ──▶ /api/*  (서버 단일 게이트)
                │
      ┌─────────┼──────────────┐
      ▼         ▼              ▼
  리스크 엔진   규정 색인      LLM
  (숫자 전담)  (검색 전담)   (설명 전담)
```

- **LLM 호출은 서버에서만.** 키를 프런트 번들에 넣지 마라
- **숫자는 엔진, 검색은 색인, 설명만 AI.** 이 경계가 곧 발표 자료의 구성도다
- 외부 API 는 전부 **캐시 + 폴백**. 하나가 죽어도 화면이 안 죽어야 한다

---

## 1. `GET /api/eua` — EUA 시세

```jsonc
// 응답
{ "spot": 79.01,            // EUR/tCO2
  "dayChangePct": 1.77,     // 전일 대비 — 화면 티커가 반드시 이 값을 쓴다
  "asOf": "2026-08-07",     // 마지막 종가일 (오늘이 아니다)
  "currency": "EUR",
  "symbol": "CO2.L",
  "recentCloses": [ /* 스파크라인용 */ ],
  "source": "Yahoo Finance · CO2.L …",
  "isProxy": true }
```

- 출처는 **CO2.L**(SparkChange Physical Carbon EUA ETC · EUA 실물 1:1 보유).
  **거래소 원장 직접 수신이 아닌 프록시**다 — 화면 각주에 그렇게 밝혀라
- 30분 캐시. 실패 시 저장소 스냅샷으로 폴백하고 `isLive: false` 를 내려보내라
- ⚠ `asOf` 는 **종가일**이라 오늘과 다르다. 환율 기준일과 뭉뚱그려 쓰지 마라

## 2. `GET /api/fx` — 환율

```jsonc
{ "usdPerEur": 1.1548157549203812,
  "krwPerEur": 1630.83,
  "asOf": "09 Aug 2026",
  "source": "open.er-api.com",
  "attribution": "Rates By Exchange Rate API",
  "attributionUrl": "https://www.exchangerate-api.com" }
```

- **키·가입 불필요.** `GET https://open.er-api.com/v6/latest/USD` → `rates.EUR`, `rates.KRW`
- **하루 1회 갱신**이라 24시간 캐시하면 레이트리밋에 안 걸린다.
  응답의 `time_next_update_utc` 를 캐시 만료로 쓰면 된다
- **조건: 화면에 출처 표기 필수** (`attribution` 을 그대로 렌더)
- ⚠ 소수점을 자르지 마라. 전체 정밀도로 계산하고 표시할 때만 반올림한다

## 3. `GET /api/sea-distance` — 항로 거리·경로

```jsonc
// 요청 쿼리: fromLng, fromLat, toLng, toLat  (위경도 필수. 항구명 아니다)
// 응답
{ "routes": {
    "A": { "nm": 11259, "path": [[lat,lng], …] },
    "C": { "nm": 14549, "path": [[lat,lng], …] } } }
```

- **오프라인 계산.** 외부 호출이 없어 심사 중 네트워크로 화면이 멈추지 않는다
- `path` 는 **지도가 그대로 그릴 좌표**다. 거리와 선이 같은 계산에서 나와야 한다
- 항로별 통과 금지·경유지는 [계산명세 §7](02_계산명세.md) 참조.
  **파나마를 빼먹지 마라**
- 계산 실패한 항로만 개별 폴백하라 — 전부 아니면 전무로 하지 마라

## 4. `POST /api/compare-routes` — 항로 2개 비교 리포트

```jsonc
// 요청: 화면이 이미 계산한 두 항로의 스냅샷을 그대로 보낸다
{ "routes": [ { "key":"A", "name":"싱가포르 경유", "status":"limited",
                "statusReason":"…", "totalUsd":2916, "baseFreightUsd":2840,
                "carbonCostUsd":67, "warRiskUsd":9, "leadTimeDays":32,
                "meetsDeadline":true }, { …두 번째… } ],
  "context": { "incoterm":"FOB", "unit":"20ft", "deadline":"2026-10-05" } }

// 응답
{ "summary":"한 문장 결론", "pros":{"A":[…],"C":[…]}, "cons":{"A":[…],"C":[…]},
  "recommendation":"…", "caveats":[…] }
```

**핵심 규칙 — 이걸 빼면 리포트가 화면과 다른 말을 한다**

- 금액은 **요청에 실려 온 값만** 쓴다. LLM 이 다시 계산하지 않는다
- `statusReason` 을 반드시 함께 보내고, 프롬프트에 이렇게 못박아라:

  > "'제한적' 또는 '운항 불가' 상태인 항로는 **결론과 단점 항목에 그 항로의 상태 사유
  > 내용을 반드시 근거로 포함해** 설명하세요. **상태만 말하고 이유를 빼지 마세요.**"

  뒷문장이 없으면 모델이 "사유를 참고했다"로 뭉갠다

## 5. `POST /api/chat` — AI 어시스턴트 단일 진입점

```jsonc
{ "botId": "auto",        // auto | nav | trip | risk | term | reg | doc
  "message": "…",
  "ctx": { "defaults": {}, "options": {}, "incotermCode": "FOB",
           "history": [ { "q":"…", "a":"…" } ] } }   // 직전 4턴만
```

| botId | 역할 | 파이프라인 |
|---|---|---|
| `auto` | 라우터 | LLM 분류 → 알맞은 봇에 위임 |
| `nav` | 길잡이 | 화면 목록 중 하나 선택 → 탭 전환 + 앵커 스크롤 |
| `trip` | 조건 파싱 | **선택 가능한 값 목록을 주입** → 없는 항목은 되묻는다 |
| `risk` | 분석 | **파라미터만** 추출 → 엔진이 계산 → 서술 |
| `term` | 계약 조항 | 조항 원문 → 인코텀즈 판정 · 비용 귀속 |
| `reg` | 규정 | §6 파이프라인 |
| `doc` | 문서 | 엔진 스냅샷 → 보고서 초안 |

**실제로 겪은 함정**

- `trip` 은 문장에 **없는 항목을 기본값으로 채우지 않는다.** 임의 기본값은 조용한 오답이다.
  못 찾은 항목은 `missing` 으로 되묻게 하라
- `term` 은 **대화 맥락을 붙이지 않는다.** 입력이 질문이 아니라 조항 원문이라 앞 턴이 섞이면
  판정이 오염된다
- 긴 문서는 생성이 잘려 **JSON 이 안 닫힌다.** 재시도하고, 실패하면 원문 앞부분을 붙여 던져라
- **LLM 게이트웨이가 HTTP 200 본문에 오류 코드를 실어 보낸다**(크레딧 소진 402).
  `res.ok` 만 보면 "응답이 비어 있음"으로 오진한다. **본문의 오류 필드를 반드시 확인하라**
- `doc` 결과 파일은 **화면에 보이는 것과 같은 내용**이어야 한다.
  다시 생성하면 화면과 파일이 달라진다

## 6. `POST /api/rag/ask` — 규정 근거 검색

```jsonc
// 요청  { "question": "모니터링 계획은 언제까지 제출해야 하나요?", "k": 4 }
// 응답  { "queryEn": "What is the deadline for submitting the monitoring plan…",
//         "hits": [ { "id":"32015R0757#art6", "doc":"MRV 해운",
//                     "cite":"Regulation (EU) 2015/757, Article 6",
//                     "score":0.95, "excerpt":"…" } ],
//         "result": { "answer":"… [1]", "used":[1], "caveat":"법률 자문이 아닙니다" } }
```

| 단계 | 무엇 | 왜 (실측 근거) |
|---|---|---|
| 1 | **조 단위 청킹** — 조 경계로 자르고 조번호·표제를 앞에 붙여 임베딩 | 문자수 윈도우로 자르면 엉뚱한 조항이 1위가 됐다 |
| 2 | **한→영 질의 변환** (실패해도 원문으로 진행) | 한국어 임베딩은 1·2위 격차가 **0.001** 로 붙었다 → 변환 후 **0.071** |
| 3 | **하이브리드** 벡터 0.6 + 키워드 0.4, **각 신호 정규화 후** 가중합 | 벡터만 쓰면 점수가 0.68~0.72 에 몰려 변별이 안 된다 |
| 4 | **인용 전용 답변** — 상위 k 조문만 근거, `[1][2]` 인용 | 근거에 없으면 답하지 않는 게 규정 도메인 최소 요건 |

### 색인을 새로 만들어야 한다면

시간이 많이 든다 — [타임박스](01_구현순서_타임박스.md)에서 T4(버릴 것)로 분류한 이유다.
그래도 한다면 **문서 1건 · 조문 20~30개**로 줄여 "동작 증명"만 하라.

| 항목 | 값 |
|---|---|
| 원문 | EU ETS 지침 통합본 · FuelEU Maritime · MRV 해운 · CBAM |
| 출처 | EUR-Lex 공개 REST(CELLAR) |
| 청킹 | **조(Article) 단위** — 조번호·표제를 본문 앞에 붙여 임베딩 |
| 색인 규모 | 153개 조 (ETS 68 · FuelEU 31 · MRV 23 · CBAM 31) |
| 임베딩 | **768차원** |
| 식별자 | `{CELEX}#art{n}` 형태로 조문마다 고유 id |

⚠ **다른 법령 상호참조를 자기 조문으로 잡지 마라.** 본문에 인용된 TFEU 조항 번호를
그대로 파싱해서 MRV 문서가 "Article 192 / 290"을 인용했다 — **실제로 없는 조다.**
문서별 **최대 조문 번호 상한**을 두고 넘으면 버려라. 174개 → **153개**로 줄었고 그게 맞다.

- 임베딩은 **768차원**으로 충분하다(3,072차원은 색인이 수십 MB가 된다)
- ⚠ 조문 파싱 시 **다른 법령 상호참조를 자기 조문으로 잡지 마라**.
  문서별 최대 조문 번호 상한을 두어라 ([함정 12](06_함정목록.md))
- **재현성**: 같은 질문 3회에 검색 상위 4개와 인용 조문이 동일해야 한다.
  영어 질의 문장은 매번 조금 달라도 된다 — 검색 결과가 흔들리지 않는 게 중요하다

## 7. `POST /api/extract-text` — 계약서 파일 → 텍스트

- 받는 형식: **PDF · DOCX · HWPX · TXT · MD** (최대 8MB)
- **원본을 서버에 저장하지 마라.** 메모리에서 텍스트만 꺼내 LLM 에 넘기고 버린다 —
  계약서는 남의 영업비밀이다
- 구형 한글 **`.hwp` 는 거부하고 사유를 답하라**([함정 15](06_함정목록.md))
- 텍스트 레이어가 없으면(스캔본 PDF) "이미지 PDF 로 보인다"고 답하라
- 추출 결과는 **바로 판정하지 말고 입력창에 채워** 사용자가 확인 후 보내게 하라

## 8. 환경변수

| 키 | 용도 | 없으면 |
|---|---|---|
| LLM API 키 | 기본 공급자 | 폴백 공급자로 전환 |
| 폴백 LLM 키 | 장애 시 자동 전환 | AI 기능만 비활성, 계산은 정상 |
| 메일 발송 키 | 목표가 알림 | 알림 등록은 되고 발송만 `pending` |

- 환율·항로거리는 **키가 필요 없다.** 이 둘만으로 T1·T2 가 전부 돌아간다

## 9. 출처 표기 의무

| 데이터 | 의무 |
|---|---|
| 환율 API | **화면에 출처 링크 표기 필수** — 응답의 `attribution` 을 그대로 렌더 |
| 지도 배경 | 퍼블릭 도메인 경계 데이터를 쓰면 표기 의무가 없다. **타일 서비스를 쓰면 표기 의무가 생기고 런타임 외부 호출도 붙는다** — 심사 중 네트워크로 화면이 멈출 수 있다 |
| 항로망 | 오픈소스 라이브러리. 라이선스 확인 후 표기 |
| EUA 시세 | 표기 의무보다 **프록시라는 사실 고지**가 중요하다 |
- ⚠ `.env` 값에 **닫히지 않은 따옴표**가 있으면 헤더에 그대로 실려 나간다.
  실제로 `Bearer "re_…` 가 나가서 인증이 조용히 실패했다. 파싱할 때 **짝이 안 맞는 따옴표를
  걷어내라**
