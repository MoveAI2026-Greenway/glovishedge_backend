# 데이터 시드 — 이 값을 그대로 넣어야 같은 화면이 나온다

[계산명세](02_계산명세.md)가 **공식**이라면 이 문서는 **입력값**이다. 둘이 맞아야
[검산표](02_계산명세.md)의 숫자가 재현된다.

**문자열은 한 글자도 바꾸지 마라.** 상태 사유·부제·각주는 화면과 AI 리포트가 **같은 문장**을
쓰도록 계산 결과에 실어 보내는 값이다. 여기서 문구가 갈리면 화면과 AI 가 다른 말을 한다.

## 5. 항로 거리 계산 — 경유지와 통과 금지

출발·도착만 넣으면 A·B·D 가 **전부 같은 값**이 된다. 구간을 이어 붙여야 실제 거리가 나온다.
경유지는 `viaText` 가 말하는 실제 기항지의 위경도다.

| 항로 | 경유지 (lng, lat) | 통과 금지 |
|---|---|---|
| A 싱가포르 | 싱가포르 `103.85, 1.28` | 없음 |
| B 홍해 | 없음 (직항) | 없음 |
| D 콜롬보 | 싱가포르 `103.85, 1.28` → 콜롬보 `79.85, 6.9` | 없음 |
| C 희망봉 | 없음 | **수에즈 · 바브엘만데브 · 파나마** |

- 각 구간을 따로 계산해 **합산**한다
- 태평양을 건너는 경로는 **경도 unwrap** 을 켠다(안 켜면 선이 지도를 가로지른다)
- 결과는 거리(nm)와 **경로 좌표**를 함께 돌려준다. 지도는 그 좌표를 그대로 그린다
- ⚠ **파나마를 빼면 희망봉이 희망봉을 안 지난다** ([함정 4](06_함정목록.md))

**기대 출력** — 부산항(35.1, 129.04) → 함부르크항 기준

| 항로 | 거리 |
|---|---|
| A · B | 11,259 nm |
| D | 11,317 nm |
| C | **14,549 nm** |

## 8. 시계열 시드 — EUA · 벙커유

### EUA

| 항목 | 값 |
|---|---|
| 런타임 이력 창 | **260 거래일** (2025-07-17 ~ 2026-07-27) |
| EWMA λ | **0.94** |
| 일간 변동성(참조) | **0.018533** |
| 연율 변동성(참조) | **29.4%** |
| 스냅샷 현재가 | 실시세 실패 시 폴백으로만 쓴다 |

- 종가 260개를 시드로 넣고 EWMA 를 **계산해서** 쓴다. 변동성을 하드코딩하지 마라
- **실시세를 받아도 변동성은 다시 계산하지 않는다.** 바뀌는 건 현재가와 기준일뿐이다
- 검증 표본 1,728일은 **별도 백테스트용**이다. 런타임에 넣지 않는다
  ([함정 16](06_함정목록.md))
- 출처는 CO2.L + GRN 스플라이싱 **프록시**. 화면에 그렇게 밝힌다

### 벙커유

- 가격 **수준**은 실제 싱가포르 VLSFO 현물가로 앵커
- **변동성은 `HO=F`(NY Harbor ULSD 선물) 프록시**다 — 무료로 얻을 수 있는 벙커유
  일별 시계열이 없다
- 화면에 "연료비 변동성은 프록시 데이터예요 · 가격 수준은 실제 VLSFO 현물가,
  변동성은 HO=F 프록시" 배너를 띄운다. 벙커유만 밝히고 EUA 를 안 밝히면 비대칭이다

## 10. 소개 화면 스탯 밴드

| 숫자 | 단위 | 설명 |
|---|---|---|
| 50 | 개 항구 | 아시아 출발 18 · 유럽 도착 32 |
| 3 | 개 비용 항목 | 운임 · 탄소 · 전쟁위험보험 |
| 100 | % 적용 | 2026년 EU ETS 배출권 제출 |
| **1,728** | 일 검증 | EUA 실측으로 구간 신뢰도 확인 |

> 소개 화면의 금액·추천 항로는 **하드코딩하지 마라.** 대시보드와 **같은 엔진·같은 기본
> 조건**으로 계산해 온다. 예전에 하드코딩했다가 소개는 "추천 = 싱가포르 $2,684",
> 시작 버튼을 누르면 "추천 = 희망봉 $3,029" 가 나왔다 — **첫 화면에서 읽은 결론이 다음
> 화면에서 뒤집혔다.**
>
> 또한 **모듈 로드 시점이 아니라 렌더 시점에 계산하라.** 상수로 한 번만 계산하면
> 환율 실시세가 도착하기 전 값이 굳어, 소개는 폴백 1.08 로 $3,023, 대시보드는 실시세로
> $3,029 를 말한다. 같은 화면 안에서 $6 이 갈렸다.
