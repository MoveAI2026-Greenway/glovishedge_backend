# GlovisHEDGE 현장 재구현 문서 — INDEX

본선 해커톤 현장에서 **코드 없이** GlovisHEDGE 를 다시 만들기 위한 문서 묶음이다.
목표 수준은 하나다 — **이 문서와 Figma 만 보고 개발 지시를 내리면 같은 것이 나온다.**

## 반입 규칙 (먼저 읽을 것)

| 가져간다 | 가져가지 않는다 |
|---|---|
| 이 폴더의 문서 전부 | **소스코드 일체**(`.js` · `.jsx` · `.py` · 설정 파일) |
| Figma 시안 (핸드오프 캔버스 `68:1735`) | 저장소 클론 · 압축본 · 빌드 산출물 |
| 기획서 · 결과보고서 | `node_modules` · `dist` · 색인 JSON |
| 프롬프트 전문 (05번 문서) | 스크린샷을 붙여넣어 만든 코드 |

**이 문서들은 "무엇을 만들지"와 "왜 그렇게 만들지"를 적은 명세다.** 공식·상수·데이터·
문구·스키마·치수·프롬프트·수용기준은 있지만 **붙여넣어 돌아가는 코드는 없다.**

> 판단 기준 하나만 기억하면 된다 — **여기 적힌 것을 보고 손으로 다시 타이핑해야 하면 명세,
> 복사해서 붙이면 바로 도는 것은 코드다.** 후자는 이 폴더에 없어야 하고, 만들어서도 안 된다.

## 제품을 한 문장으로

> **운임만 보면 뒤집히는 해상운송 총비용을, 실행 가능한 항로 안에서 결정한다.**

- **총비용** — 운임 + 탄소비용(EU ETS) + 전쟁위험보험료. 운임표에는 뒤 둘이 없다
- **실행 가능한** — 최저가와 실행가능성은 다른 질문이다. 숫자상 1위여도 못 가면 추천하지 않는다
- **결정한다** — 가격의 방향은 예측하지 않는다. 구간과 확률만 준다

## 절대 흔들리면 안 되는 주장 세 가지

현장에서 시간에 쫓기면 가장 먼저 무너지는 것들이다. **이게 무너지면 제품이 아니라 데모가 된다.**

1. **가격의 방향을 예측하지 않는다.** 실측 1,728일 워크포워드에서 재학습 24회 전부
   AIC 가 랜덤워크를 골랐다. "최적 선적일 권고"는 그 결과를 받아 **접은 주장**이다
2. **운항 불가 항로는 총비용을 만들지 않는다.** 접힌 행뿐 아니라 **펼친 패널에서도**
   금액이 없어야 한다 ([함정 3](06_함정목록.md))
3. **LLM 은 숫자를 만들지 않는다.** 금액·확률은 엔진 계산값만 쓴다

셋 다 **구현량이 0 이고 심사에서 가장 강한 부분**이다. 시간이 없다고 무너뜨릴 이유가 없다.

## 용어 — "화주"라고 쓰지 말 것

화주는 **운송을 수배하는 쪽**이라 인코텀즈에 따라 바뀐다 — FOB 면 매수인이, CIF 면
매도인이 화주다. 그래서 "화주 직접 지출"이라고 쓰면 FOB/CIF 가 서로 뒤바뀐 것처럼 읽힌다.
**실제로 팀 내에서 지적받은 적이 있다.** 비용 귀속은 **매도인 / 매수인**으로 못박는다.

(제품의 사용자를 가리킬 때는 "화주"를 써도 된다.)

## 30초 안에 승부가 나는 장면

> **운임 최저는 싱가포르($2,840)인데, 실제로 추천되는 건 희망봉($3,200)이다.**

이 장면이 뜨면 나머지가 없어도 제품이다. 없으면 나머지가 다 있어도 데모다.
그래서 [타임박스](01_구현순서_타임박스.md)의 T1 이 이것 하나로 짜여 있다.

## 현장 산출물 셋 — 일정 감각

| 산출물 | 언제 | 선행 조건 |
|---|---|---|
| **데모 앱** | 계속 | — |
| **발표자료** | 앱 T1 완료 후 병렬로 시작 | 캡처가 필요하니 화면이 떠야 한다 |
| **영상** | **마지막** | 앱 T2 까지 돌아가야 찍는다 |

**영상을 마지막에 두되 시간을 남겨둬라.** 나레이션 → TTS → 녹화 → 렌더 → 전 문장 대조까지
한 바퀴가 짧지 않고, 화면-낭독이 어긋나면 그 씬을 다시 찍어야 한다.

발표자료는 앱과 **병렬로** 진행할 수 있다 — 캡처만 나오면 나머지는 글이다.
