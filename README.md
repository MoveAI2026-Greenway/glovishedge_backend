## 설계 결정 — 이 서버는 숫자를 계산하지 않는다

```
숫자는 엔진이 · 검색은 색인이 · 설명만 AI가
```

총비용·항로 거리·리스크는 전부 **순수 함수**라 브라우저에서 돈다(프런트 저장소 `src/engine/`).
이 서버가 맡는 것은 **서버여야만 하는 것**뿐이다:

| 왜 서버인가 | 무엇 |
|---|---|
| 키를 브라우저에 노출할 수 없다 | LLM 게이트 (Gemini) |
| 색인이 크고 임베딩 호출이 필요하다 | 규정 RAG (1.7MB · 175개 조문) |
| CORS·레이트리밋·캐시가 필요하다 | EUA 선물 시세 · 환율 프록시 |

그래서 **프런트 코드를 한 줄도 import 하지 않는다.** 두 저장소가 서로를 모른다.

```
브라우저 ──▶ /api/*  ──┬─▶ 규정 색인   (검색 전담)
                        ├─▶ LLM         (설명 전담 · 키는 여기서만)
                        └─▶ 외부 시세   (캐시 + 폴백)
```

## API

| 엔드포인트 | 하는 일 |
|---|---|
| `GET /api/eua` | ICE EUA 선물 실시간 시세. **3중 폴백**(TradingView → Investing → Barchart), 전부 실패하면 `spot: null` 을 돌려주고 **프런트가 검증 계열 마지막 종가로 폴백**한다 |
| `GET /api/fx` | USD/EUR 환율 (24시간 캐시 · 상수 폴백 · 출처 표기 의무) |
| `POST /api/compare-routes` | 항로 2개 비교 리포트. **금액은 요청에 실려 온 값만 인용** — LLM 이 다시 계산하지 않는다 |
| `POST /api/chat` | AI 어시스턴트 단일 진입점 (라우터 · 조건 파싱 · 계약 조항 판정 · 문서 생성) |
| `POST /api/rag/ask` | 규정 근거 검색 — 조문 인용 답변 |
| `GET /api/health` | 서브시스템 상태 |

정적 파일이 `dist/` 에 있으면 함께 서빙한다(SPA 폴백 포함). 없으면 API 전용으로 뜬다.

## 규정 RAG — 175개 조문

| 문서 | CELEX | 조문 |
|---|---|---|
| EU ETS 지침 통합본 | `02003L0087-20240301` | 81 |
| FuelEU Maritime | `32023R1805` | 32 |
| MRV 해운 | `32015R0757` | 26 |
| CBAM | `32023R0956` | 36 |

- **조(Article) 단위 청킹** — 문자수 윈도우로 자르면 엉뚱한 조항이 1위가 된다.
  EUR-Lex 가 붙이는 구조 앵커(`div.eli-subdivision`)로만 잘라 상호참조 오염이 0건이다
- **하이브리드 검색** — 벡터 0.6 + 키워드 0.4, 각 신호를 정규화한 뒤 가중합
- **한→영 질의 변환** — 한국어를 그대로 임베딩하면 1·2위 점수 격차가 0.001 로 붙는다.
  다만 LLM 번역은 `temperature: 0` 에서도 결정적이지 않아, 질의 벡터를
  **한국어 원문 0.65 + 영문 번역 0.35** 로 섞어 순위를 안정화했다(임베딩은 완전히 결정적)
- **인용 없으면 답하지 않는다** — 근거에 없으면 `제공된 조문에서는 확인되지 않습니다`

재현성 검증: 서로 다른 프로세스 3회에서 상위 4개 조문과 인용이 동일.

## 실행

```bash
npm install
npm run build:rag   # 색인 재생성 (index.json 이 이미 있으면 생략 가능)
npm start           # http://localhost:8080
```

### 환경변수

| 키 | 용도 | 없으면 |
|---|---|---|
| `GOOGLE_AI_STUDIO_KEY` | LLM · 임베딩 | AI 기능만 비활성, **계산 기능은 프런트에서 정상 동작** |
| `PORT` | 포트 | 8080 |

환율·시세는 **키가 필요 없다.**

## 알아 둘 것

- **LLM 게이트웨이가 HTTP 200 본문에 오류를 실어 보낸다.** `res.ok` 만 보면
  "응답이 비어 있음"으로 오진한다 — 본문의 오류 필드를 확인한다
- **Gemini 는 사고 토큰이 출력 예산을 먼저 먹는다.** `maxOutputTokens` 를 짜게 잡으면
  JSON 이 첫 문장에서 잘린다(1600 으로 두었더니 97자에서 끊겼다). 8192 로 둔다
- **EUA 선물 시세 3경로는 전부 스크래핑이다.** 공식 API 가 아니라 `source` 에 그렇게 밝힌다.
  장기 운영에는 유료 피드(ICE/Refinitiv)로 갈아타야 한다
- `.env` 값에 닫히지 않은 따옴표가 있으면 헤더에 그대로 실려 나간다 — 파서가 걷어낸다
